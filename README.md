# youtube-dl (YoupyTube)

A program to download videos from Youtube.

Instructions :

1. Install `requirements.txt`

2. Run the next instruction

`streamlit run app.py`

The app is opening in your web browser.

3. Paste a youtube link

4. Click on MP4 or MP3

5. Your audio or video file is downloaded in a folder named `files` inside the folder's project `youtube-dl`
